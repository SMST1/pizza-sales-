🍕 PizzaHut Sales Analysis with SQL 📈📊

Just wrapped up this hands-on project where I explored and analyzed sales data from a PizzaHut database using SQL!
Here’s what I uncovered:
 ✅ Total orders placed & revenue generated
 ✅ Top-selling pizza types by quantity and revenue
 ✅ Most popular pizza sizes and categories
 ✅ Hourly order patterns and daily pizza demand
 ✅ Revenue share by each pizza type & cumulative growth over time
 ✅ Deep dive into category-wise performance

🔍 The database involved multiple connected tables: orders, order_details, pizzas, and pizza_types, giving me a great chance to practice:
Complex SQL joins
Aggregations and window functions
CTEs and subqueries
Time-based trend analysis

✨ This project helped me turn raw order data into actionable business insights — something every pizza chain (real or fictional!) could use.
If you're into food + data (who isn't? 😄), you'll enjoy this project.
